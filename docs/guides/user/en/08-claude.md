# Connecting Claude

You can connect your Claude (claude.ai, the desktop app or Claude Code) to Postaja. In a conversation Claude can then send the CGP, materials and files from your projects straight to a brand, and you review everything in Postaja.

## How to connect

1. Open **Claude** in the menu and copy the **MCP server URL**.
2. In Claude open **Settings → Connectors** and add a custom connector named Postaja with this URL.
3. Click **Connect**, sign in to Postaja and allow access.
4. In a conversation say, e.g., “Send this CGP to Postaja for the brand inzenirji”.

## What Claude can do

- read brands, CGPs, channels and the list of materials;
- an owner can **propose a CGP** through Claude: it is stored as a proposal that you insert into the editor in the brand profile and save (or discard);
- add text materials and files (logo, images, documents, fonts);
- create a new brand.

Claude cannot publish, delete or change settings. You end the connection on the **Claude** page with **Disconnect**, where you also see Claude's recent actions.
