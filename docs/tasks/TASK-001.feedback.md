## Deviations from the task (and why)
- Inter self-hosted via `next/font/local` instead of `next/font/google`: Google Fonts unreachable in the sandbox, and self-hosting avoids sending EU visitors' IPs to Google. Subset Latin + Latin Extended (~40 KB per weight), OFL licence in `src/app/fonts/README.md`.
- E2E runs `.next/standalone/server.js` (not `next start`) so tests exercise exactly what the image runs.
- Migrations run from `instrumentation.ts` instead of a shell entrypoint, so the migrator is traced into the standalone bundle automatically (same behaviour as ADR-024).
- ADR-017 dev host corrected to `dev-postaja.inzenirji.si` before the first commit (owner correction; never published with the old value).
